## Release managers

Release managers hold publish rights for `@sidioralabs/rex` on npm and push the `v*` release tags.

- [@dev-paxeer](https://github.com/dev-paxeer)

The project currently has one release manager. [GOVERNANCE.md](GOVERNANCE.md) requires the maintainers to appoint a second as soon as a qualified contributor is nominated.
